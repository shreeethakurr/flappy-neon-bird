# Flappy Neon

A polished Flappy Bird-inspired arcade game built from scratch with HTML5 Canvas, CSS and vanilla JavaScript.

## Features
- Smooth gravity + flap physics
- Procedurally generated pipe gaps
- Increasing difficulty
- Collision detection
- Score + persistent best score
- Particle effects
- Neon animated background
- City silhouette
- Screen shake
- Synth-style sound effects
- Pause / restart
- Keyboard, mouse and mobile touch controls
- No framework or build step

## Run
Open `index.html` in a modern browser.

Or:
```bash
python3 -m http.server 8000
```

## Controls
SPACE / ARROW UP / CLICK / TAP — Flap
P / ESC — Pause
